DakFlare treats AI coding agents (Claude Code, Cursor, Windsurf, OpenCode, and autonomous workflows) as a first-class audience served from the same source of truth as the human documentation.

## Machine-Readable Endpoints

| Endpoint | Format | Purpose |
| --- | --- | --- |
| [`/llms.txt`](/llms.txt) | Markdown index | Concise navigation index ordered by onboarding priority with one-line descriptions |
| [`/llms-full.txt`](/llms-full.txt) | Concatenated Markdown | Complete documentation bundle with `llms-ignore` JSX stripped and `llms-only` context preserved |
| `/docs/{any-path}.md` | `text/markdown; charset=utf-8` | Clean source Markdown for any page (e.g. `/docs/start/quickstart.md`, `/docs/reference/api-reference.md`) |
| `Accept: text/markdown` | HTTP content negotiation | Any doc URL returns clean Markdown with `Vary: Accept` and `x-markdown-tokens` budget header |
| [`/openapi.json`](/openapi.json) | OpenAPI 3.1.0 JSON | The 17 operations the API playground covers (pairing, poll, status, send, devices, messages, one workflow route, the four `/v1/agent/*` endpoints, webhooks, health, auth mode, `/mcp`), with security schemes, request/response examples, and error shapes |
| [`/SKILL.md`](/SKILL.md) | Agent Skill Markdown | Curated single-file skill encoding DakFlare invariants, CLI rules, Wasm ABI, and Do/Don't guardrails |
| [`/AGENTS.md`](/AGENTS.md) | Repository Agent Guide | Repo-root instructions for coding agents working directly inside `dakflare` |
| `POST /mcp` | JSON-RPC 2.0 (Docs MCP) | Live retrieval tools: `list_sections`, `search_docs`, `get_doc_page`, `get_openapi_operation` |

## Fetching Markdown Directly

```bash
# Via explicit .md route
curl -sS https://docs.dakflare.dev/docs/start/quickstart.md

# Via HTTP content negotiation (returns x-markdown-tokens header)
curl -i -H "Accept: text/markdown" https://docs.dakflare.dev/docs/reference/mcp-tools/
```

## Querying the Docs MCP Server

```bash
curl -sS -X POST https://docs.dakflare.dev/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_openapi_operation","arguments":{"path":"/v1/sms/send"}}}'
```

## Installing DakFlare's Task-Specific Skills

In addition to the unified [`/SKILL.md`](/SKILL.md), the repository ships four modular skills under `skills/` compatible with `npx skills add`:
- `skills/dakflare-provision/SKILL.md` — install, deploy, repair, pair, revoke
- `skills/dakflare-messaging/SKILL.md` — async send, idempotency, delivery status
- `skills/dakflare-flows/SKILL.md` — `dakflare.flow/v2` authoring, validation, drift healing
- `skills/dakflare-agents/SKILL.md` — `dkf_agt_` tokens, grants, approvals, `/mcp`
