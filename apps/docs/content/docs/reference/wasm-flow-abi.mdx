DakFlare compiles its pure-Rust flow engine (`simulator/flow`) to `wasm32-unknown-unknown` (`simulator/flow-wasm/build.sh` → `worker/src/wasm/flow.wasm` and `dashboard/static/flow.wasm`) without `wasm-bindgen`, so Cloudflare Workers can instantiate the module synchronously with zero loader glue.

## Binary Framing Contract

Every call passes UTF-8 JSON into linear memory and returns a pointer to a length-prefixed frame:

```text
[ 4 bytes: u32 little-endian payload length ][ payload UTF-8 JSON bytes ]
```

**Critical safety rule**: Always construct fresh `DataView` / `Uint8Array` views over `wasm.memory.buffer` *after* calling any exported function—allocation inside Wasm can grow linear memory and detach previously captured ArrayBuffer views. Always call `dealloc(outPtr, 4 + length)` and `dealloc(inputPtr, inputLen)` to free both buffers.

## Exported C ABI Functions (`simulator/flow-wasm/src/lib.rs`)

| Export | Signature | Input JSON | Output JSON |
| --- | --- | --- | --- |
| `alloc` | `(len: usize) -> *mut u8` | — | Allocates `len` bytes in Wasm memory |
| `dealloc` | `(ptr: *mut u8, len: usize) -> void` | — | Frees a buffer returned by `alloc` or a `*_json` function |
| `run_json` | `(ptr, len) -> *mut u8` | `{ graph, message: { sender, body, received_at } }` | `FlowResult`: `{ matched, outcome, actions, variables, steps, error? }` |
| `validate_json` | `(ptr, len) -> *mut u8` | Raw flow graph object | `{ ok: true, graph }` (stamped with `schema` & `rank-v1` `ui_layout`) or `{ ok: false, issues }` |
| `layout_json` | `(ptr, len) -> *mut u8` | Raw flow graph object | `{ ok: true, algorithm: "rank-v1", positions: { [id]: { x, y } } }` |
| `trace_json` | `(ptr, len) -> *mut u8` | `{ graph, message }` | Validates then runs: `{ ok: true, trace: FlowResult }` or `{ ok: false, issues }` |
| `synthesize_json` | `(ptr, len) -> *mut u8` | `{ samples: [{ body, value }], negatives?: string[], group?: string }` | `{ ok: true, result: { pattern, group, precision, recall, ... } }` or `{ ok: false, reason, message }` |
| `synthesize_template_json` | `(ptr, len) -> *mut u8` | `{ sample_body, spans: TemplateSpan[], additional_samples? }` | `{ ok: true, result: { pattern, trigger_phrases, variables, test_results } }` |
| `suggest_spans_json` | `(ptr, len) -> *mut u8` | `{ body: string }` | `{ ok: true, spans: TemplateSpan[] }` |

## Canonical Flow IR (`dakflare.flow/v2`)

Derived from `cli/schema/flow-v2.json` and `worker/src/lib/flow-ir.ts`:

### Node Kinds (9 Total)

| `type` | Required `data` Fields | Outgoing `sourceHandle` Rules |
| --- | --- | --- |
| `trigger` | `kind: "incoming"`, optional `sender: { mode: any\|exact\|prefix\|regex, value? }`, `body: { mode: any\|keyword\|regex, value? }` | 1 unlabelled edge; binds `sender`, `body`, `received_at` |
| `extract` | `pattern` (RE2, 1–512 chars, ≥1 `(?<name>...)` group), optional `source: "body"\|"sender"`, `flags: ""\|"i"` | 1 unlabelled edge; binds named capture groups |
| `set_var` | `name` (`^[A-Za-z_][A-Za-z0-9_]{0,31}$`, not builtin), `value` (template ≤2048 chars) | 1 unlabelled edge |
| `condition` | `left` (template), `op: equals\|not_equals\|contains\|matches\|exists`, `right?` (required unless `exists`) | 2 edges: `true` and `false` |
| `switch` | `value` (template), `cases: string[]` (1–8 items) | `case:0` .. `case:<n-1>` plus `default` |
| `delay` | `seconds` (integer `1..300`) | 1 unlabelled edge (>5s runs in `FlowExecutionWorkflow`) |
| `webhook` | `url` (`^https://`, SSRF-checked: no loopback/private/CGNAT/metadata), optional `body` template | 1 unlabelled edge (dispatched via `WEBHOOK_QUEUE`) |
| `send_sms` | `to` (1–32 chars), `body` (1–4096 chars) | 1 unlabelled edge |
| `stop` | `{ reason?: string }` | 0 outgoing edges |

### Structural Limits

| Constraint | Limit |
| --- | --- |
| Max nodes (`flow-v2.json` / `config.ts`) | 200 in IR schema (50 in legacy `MAX_WORKFLOW_NODES` guard) |
| Max edges (`flow-v2.json` / `config.ts`) | 400 in IR schema (100 in legacy `MAX_WORKFLOW_EDGES` guard) |
| Max graph serialized size | 65,536 bytes (`MAX_WORKFLOW_GRAPH_BYTES`) |
| Node / edge ID pattern | `^[A-Za-z0-9_-]{1,64}$` |
| Variable template syntax | `{{ name }}` or `{{ vars.name }}` (must be bound on every incoming path) |
| Topology | Strictly acyclic DAG; cycles rejected with offending edge |
